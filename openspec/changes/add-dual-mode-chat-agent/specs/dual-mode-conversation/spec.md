# dual-mode-conversation 规格

## ADDED Requirements

### Requirement: 普通对话模式流式直答
系统 SHALL 在普通对话模式下将用户消息直接送入 LLM（GLM），并通过 SSE 以流式方式返回回复，不经过 Agent 工具循环。

#### Scenario: 普通消息获得流式回复
- **WHEN** 用户在普通对话模式发送一条消息
- **THEN** 系统调用 LLM 生成回复，前端通过 SSE 逐段接收并渲染

#### Scenario: 普通对话不触发工具执行
- **WHEN** 用户在普通对话模式询问知识型问题
- **THEN** 系统仅返回模型文本回复，不创建任务、不产生产物

### Requirement: 模式显式切换
系统 SHALL 允许用户在会话中显式切换普通对话模式与工作模式，切换后的消息按新模式处理。

#### Scenario: 用户切换到工作模式
- **WHEN** 用户点击模式开关切换到工作模式并发送消息
- **THEN** 该消息进入 Agent 任务流程而非 LLM 直答

#### Scenario: 工作模式切回普通对话
- **WHEN** 用户从工作模式切回普通对话模式并发送消息
- **THEN** 该消息按普通对话直答处理，已有产物保留且可继续访问

### Requirement: 会话管理
系统 SHALL 支持创建会话、列出当前用户的会话、恢复历史会话并延续上下文。

#### Scenario: 恢复历史会话
- **WHEN** 用户打开一个历史会话并发送新消息
- **THEN** 系统携带该会话既有上下文继续对话

#### Scenario: 会话按用户隔离
- **WHEN** 用户列出会话
- **THEN** 仅显示该用户自己的会话

### Requirement: 工作模式消息通道
系统 SHALL 在工作模式下将用户消息全部送入 Agent 对话流，消息语义由 Agent 当前状态（执行中/预览就绪）决定。

#### Scenario: 工作模式消息不经过闲聊判断
- **WHEN** 用户在工作模式发送任意消息（包括疑问句）
- **THEN** 系统将其交给 Agent 处理，不做任务/闲聊分类
