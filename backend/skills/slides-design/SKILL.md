# 幻灯片设计指南

做 PPT 类任务时遵循本指南,通过 `save_slides` 落地。

## 1. 选主题(theme 参数,按内容气质对号)

| theme | 气质 | 适用 |
|-------|------|------|
| `midnight` | 午夜藏青,稳重商务 | 商业计划、汇报、金融 |
| `teal` | 青碧,科技信任感 | 产品、技术、数据类 |
| `forest` | 森林苔绿,自然沉稳 | 环保、健康、农业 |
| `coral` | 珊瑚暖色,活泼有能量 | 营销、活动、教育 |
| `charcoal` | 炭灰极简,克制高级 | 设计、极简风格偏好 |
| `berry` | 浆果奶油,温润优雅 | 文化、生活方式、品牌故事 |

## 2. 版式规划(每页 layout 参数)

- 结构采用"三明治":**封面(深色)→ 内页(浅色)→ 结尾(深色)**。
  封面与结尾由工具自动补齐(无封面时用 deck 标题自动生成),你规划中间页。
- 页数 > 6 时,用 `section` 章节页分段(每段一张,标题 = 章节名,bullets 留空)。
- 内容页 `layout: "content"`(默认):每页 bullets **3~6 条**,每条 ≤ 40 字,一个短标题概括一页主题。
- 关键数字写成"数值 + 说明"短句(如「37% 复购率提升」),工具会渲染为大数字卡片。
- 不要把长段落塞进 bullets;宁可多拆几页。

## 3. 内容质量

- 标题写结论/观点,不写「介绍」「概述」这类空词。
- bullets 动宾短语或数字论据,信息具体,不写占位话。
- 全篇页数:一般 5~10 页;用户指定页数则严格遵从。

## 4. 保存调用示例

```json
{
  "title": "2026 秋季新品发布",
  "theme": "coral",
  "slides": [
    {"layout": "cover", "title": "2026 秋季新品发布", "subtitle": "让温暖触手可及"},
    {"layout": "section", "title": "市场洞察"},
    {"layout": "content", "title": "年轻客群正在重新定义「家」", "bullets": [
      "62% 的 95 后愿为设计感支付溢价",
      "「氛围感」搜索量三年增长 4 倍"
    ]},
    {"layout": "end", "title": "谢谢观看", "subtitle": "期待合作"}
  ]
}
```

## 5. 禁忌(出「AI 味」的根源)

- 禁止每页都是「标题+一串 bullets」的重复节奏——用 section 页和数字卡片制造变化。
- 禁止超长文字、整段搬运;禁止占位内容(「更多内容」「待补充」)。
- 用户给了品牌色/风格偏好时,选最接近的 theme 并在回复中说明。
